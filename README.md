# Nexus Bütünleşik Karar Destek Sistemi

Bu proje, AHP, TOPSIS, TSP ve K-Means gibi çeşitli optimizasyon ve karar destek algoritmalarını içeren, Streamlit tabanlı bir web uygulamasıdır.

## Kurulum

Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:

1. Depoyu klonlayın
2. Gerekli kütüphaneleri yükleyin: `pip install -r requirements.txt`
3. Uygulamayı başlatın: `streamlit run app.py`

## Kullanılan Teknolojiler
* Python
* Streamlit
* Optimizasyon Algoritmaları
